## Reproducing these results

```bash
# 1. Start infra
docker compose up -d

# 2. Ingest corpus (Phase 1)
uv run python -m backend.ingestion.run --tickers all

# 3. Build indexes (Phase 2)
uv run python -m backend.indexing.embed_corpus
uv run python -m backend.indexing.build_indexes

# 4. Dev-set eval (fast, no cost)
uv run python -m backend.eval.run_eval --suite dev

# 5. Full ablation (all 5 configs, ~2–4h on Groq free tier)
uv run python -m backend.eval.run_eval --suite full --judge
```
